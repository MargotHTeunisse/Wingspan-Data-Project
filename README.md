## What have I landed on?

This is a personal project revolving around the popular bird-themed board game Wingspan. I enjoy the game very much, and had the idea that it could be the basis for a nice little data analysis project, which could also help me to get a better grip on SQL and the way that it combines with general programming languages.

I have started by playing around with the relational database structure for the base and European birds, which I have dumped to wingspan.sql. Next, I would like to formulate a set of research questions and make observations about the birds. I plan to use Python for this, since I'm greatly familiar with it and it synergizes well with data analysis.

I've currently put this project on hold to focus more on my other personal project to build a [language learning application in Java](https://github.com/MargotHTeunisse/LangLearnerApp), and on getting my homepage set up. Once these are further along, I hope to get back to this project.
